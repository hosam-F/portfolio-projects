# Windows Forms Encryption Assignment

## Project Type

C# Windows Forms academic assignment.

## Overview and Objective

The project provides a desktop interface for educational cryptography exercises, including RSA-related code and custom Latin/Arabic classical transformation routines.

## Technologies

C#, Windows Forms, .NET Framework 4.8, System.Security.Cryptography, and Visual Studio project files.

## Main Files

The main implementation is under `hosam algorafi/hosam algorafi/THE HW1 ALL ENCRAPTION/`, with forms, designer files, resources, configuration, and a `.csproj` file.

## How to Run

Open the solution in Visual Studio on Windows with .NET Framework 4.8 developer tools and build the project. A successful build was not claimed in the Linux sandbox.

## Status

Academic project prepared for source review. Generated `.suo` files were removed; source code and resources were preserved. The project is not described as a production-grade cryptography library.
