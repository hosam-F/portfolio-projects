# Windows Forms Encryption Assignment

## Overview

This is a C# Windows Forms academic project targeting .NET Framework 4.8. The source contains multiple cryptography demonstrations in a desktop interface.

## Technologies

- C#
- Windows Forms
- .NET Framework 4.8
- `System.Security.Cryptography` for RSA-related code
- Custom implementations for classical cipher exercises, including Hill-style matrix operations and Arabic/Latin transformations

## Structure

The main project is located at:

`hosam algorafi/hosam algorafi/THE HW1 ALL ENCRAPTION/`

Important files include `Form1.cs`, `Form2.cs`, their designer/resource files, `Program.cs`, `App.config`, and the `.csproj` file.

## Running

Open the solution in Visual Studio on Windows with the .NET Framework 4.8 developer tools installed, then build the solution. The current Linux sandbox does not provide the Windows Forms/.NET Framework toolchain, so a successful build is not claimed here.

## Current Status

Academic desktop assignment requiring Windows-based build verification. The code and project files are preserved; no cryptographic algorithm or behavior was changed during this preparation.

## Security and Scope Note

This project demonstrates educational cryptography exercises. It must not be described as a production-grade encryption library or security system without a separate security review.
