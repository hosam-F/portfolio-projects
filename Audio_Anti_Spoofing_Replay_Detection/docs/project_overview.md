# Project Overview

## المشكلة
يمكن أن يحتوي التسجيل الصوتي على صوت حقيقي أو على نسخة أُعيد تشغيلها من مكبر صوت أو جهاز آخر. يهدف المشروع إلى بناء مصنف أكاديمي صغير يميز بين الحالتين.

## الهدف
تصنيف ملف WAV إلى **GENUINE / Bona Fide** أو **REPLAY / Replay Spoofing Attack**.

## المدخل والمخرج
المدخل تسجيل صوتي. المخرج الفئة المتوقعة، مع درجة ثقة للنموذج عند توفرها.

## الأهمية
يساعد كشف هجمات إعادة التشغيل على رفع موثوقية أنظمة التحقق الصوتي، مع الحفاظ على نطاق تعليمي قابل للفهم والتنفيذ محليًا.

## الحالة الحالية
هذه وثيقة تأسيسية؛ لا تتضمن نتائج تجريبية أو ادعاءات أداء.
