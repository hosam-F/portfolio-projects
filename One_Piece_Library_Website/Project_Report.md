# One Piece Library Website

## Project Type

Arabic RTL static web project.

## Overview and Objective

The site presents the products and services of One Piece Library, including school supplies, printing, event preparation, gifts, and mobile accessories.

## Technologies

HTML5, CSS3, and local image assets.

## Main Features

The page contains sections for the library overview, products, services, product details, and a public-contact placeholder. The interface was reorganized visually with responsive RTL styling, cards, improved navigation states, and mobile adjustments.

## Database

SQL scripts exist under `binyan.sql/`, but the current HTML has no backend or database connection. The project is therefore static in its current state.

## How to Run

Open `nootbook.html` in a browser or serve the folder with a static web server.

## Status

Front-end/static project prepared for review. It is not a database-connected application and is not claimed to be full-stack.

## Remaining Work

Add approved public contact details and confirm image/content rights before any public publication. A backend connection would require a separate implementation decision.
