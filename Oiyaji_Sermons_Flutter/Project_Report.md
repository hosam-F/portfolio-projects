# Oiyaji Sermons Flutter

## Project Type

Flutter mobile application project.

## Overview and Objective

The application is intended to present sermons, lessons, books, and educational content associated with Sheikh Mohammed Al-Jarafi.

## Technologies

Flutter/Dart, Provider, SQLite through sqflite, PDF viewing, localization, shared preferences, URL launching, sharing, cached network images, and Tajawal font assets.

## Structure

The project contains models, local data/database code, presentation providers and screens, reusable widgets, assets, Android/iOS platform folders, and an additional `screens/` tree requiring consolidation review.

## How to Run

With a configured Flutter SDK, run `flutter pub get`, `flutter analyze`, `flutter test`, and `flutter run` from the project root. Flutter was not available in the current sandbox, so no new build or test success is claimed.

## Status

Real Flutter project requiring cleanup and completion review. `android/local.properties` is machine-specific and ignored; generated `android/.gradle` was removed. The project is not claimed to be production-ready.
