# المعجم العربي للمشروع

| المصطلح | المقصود داخل المشروع |
|---|---|
| المؤسسة | أعلى سياق تنظيمي في البيانات |
| المركز | سياق تشغيلي تابع للمؤسسة عندما تدعمه النمذجة المعتمدة |
| الحلقة | وحدة تعليمية مرتبطة بالمؤسسة/المركز |
| المجموعة | مجموعة تشغيلية داخل الحلقة |
| الطالب | سجل المتعلم المرتبط بالمجموعة |
| اليوم | الاسم الظاهر للحضور؛ المعرف الداخلي التقني ما زال `session` |
| المنهج | سجل منهجي له إصدار وحالة ومجالات ووحدات |
| التقدم | سجل قياس تقدم الطالب ونسبة الإنجاز |
| الملاحظة | شاهد تربوي مرتبط بالطالب واليوم والمربي |
| المربي | مستخدم أو صاحب دور تعليمي داخل الصلاحيات |
| controlled-runtime | بيئة الاختبارات الاصطناعية المعزولة |
| production-runtime | بيئة التشغيل المحلية الفعلية |
| Smoke | اختبار مسار اصطناعي رأسي يشمل قاعدة البيانات والتقرير والبحث والنسخ |
| Artifact | ملف One-Folder أو Installer قابل للبصم والتحقق |
| Gate | بوابة اعتماد لا تُفتح بمجرد نجاح اختبار واجهة |
| TEST DATA ONLY | وسم إلزامي للبيانات الاصطناعية |
