# بيئة إعادة إنشاء النظام

هذا المجلد يوثق بيئة التطوير اللازمة لإعادة بناء المشروع دون حفظ أسرار أو كلمات مرور. البيئة التنفيذية الحالية موجودة في `D:\quran\.venv`، وملف الاعتماديات المرجعي هو `D:\quran\requirements.txt`. لا تُنسخ البيئة الافتراضية إلى جهاز إنتاج؛ تُعاد إنشاؤها من ملف الاعتماديات داخل مسار عمل معزول.

| المكوّن | الاستخدام |
|---|---|
| Python 3.12.x | تشغيل المصدر وبناء Windows |
| PySide6 | الواجهة وRTL |
| SQLAlchemy وSQLite | التخزين المحلي والطبقة العازلة |
| ReportLab | التقارير المحلية |
| PyInstaller | بناء One-Folder/EXE |
| Inno Setup | بناء Installer |

يجب تسجيل الإصدارات الفعلية والبصمات في Manifest كل مرحلة. لا يُحفظ في هذا المجلد أي ملف اعتماد أو كلمة مرور أو token أو قاعدة بيانات إنتاج. تُحفظ أدوات VMware وملفات VM خارج هذا المشروع ولا تُنقل إلى الحزمة البرمجية.

## إعادة الإنشاء العامة

أنشئ بيئة Python جديدة، ثبّت الاعتماديات من `requirements.txt`، اضبط `PYTHONPATH` إلى `D:\quran\src`، ثم شغّل اختبارات المصدر قبل البناء. بعد نجاح المصدر، ابنِ One-Folder ثم Installer في مجلد Phase مستقل. لا تستبدل بيئة أو artifact تاريخيًا.
