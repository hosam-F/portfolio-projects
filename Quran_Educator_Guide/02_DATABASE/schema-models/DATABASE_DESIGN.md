# التصميم المنطقي لقاعدة البيانات

هذه الوثيقة تصور منطقي فقط. لا تنشئ جداول أو ملف قاعدة بيانات، ولا تفرض أسماء نهائية قبل مراجعة المجال.

## مبادئ عامة

تستخدم SQLite محليًا عبر SQLAlchemy. لكل سجل معرف داخلي ثابت، وتاريخ إنشاء وتعديل حيث يلزم، ومصدر تعديل. تُفصل بيانات المحتوى عن بيانات التشغيل. تُستخدم الحذفيات المنطقية أو حالات الأرشفة للسجلات التي يجب الاحتفاظ بأثرها، ولا تُحذف سجلات تربوية تاريخية حذفًا صامتًا.

## الكيانات المقترحة

| الكيان | الغرض | العلاقات الأساسية |
|---|---|---|
| Organization | مؤسسة أو مسجد مستقبليًا. | يملك حلقات ومستخدمين ومحتوى منشور. |
| Circle | بيانات الحلقة والهوية والجدول العام. | ينتمي إلى Organization ويرتبط بمجموعات ومعلمين. |
| Group | مجموعة تعليمية داخل الحلقة. | ترتبط بطلاب ومعلم ومواعيد. |
| Person | أصل مشترك للأشخاص المحليين. | يتخصص إلى Student أو Teacher أو Guardian عند الحاجة. |
| Student | ملف الطالب والمرحلة والأهداف. | يرتبط بالمجموعة والحضور والسجلات والمشروعات. |
| GuardianLink | علاقة الطالب بجهة تواصل مصرح بها. | تربط Student بجهة اتصال بأقل بيانات ممكنة. |
| TeacherAssignment | إسناد معلم أو مرب مساعد. | يربط Person بالحَلقة أو المجموعة وفترة الصلاحية. |
| ScheduleEntry | موعد الحصة. | يرتبط بالحَلقة أو المجموعة. |
| AttendanceRecord | حضور جلسة محددة. | يرتبط بالطالب والموعد ومؤلف السجل. |
| Observation | ملاحظة تربوية مؤرخة. | ترتبط بالطالب أو الحصة مع مستوى خصوصية. |
| SurahReference | مرجع السورة دون افتراض تخزين المصحف كاملًا. | يملك مقاطع مرجعية. |
| QuranSection | مقطع أو نطاق مرجعي. | يرتبط بسورة وسجلات الحفظ والمراجعة. |
| MemorizationRecord | إنجاز حفظ أو تسميع. | يرتبط بالطالب والمقطع والجلسة. |
| ReviewRecord | مراجعة وإتقان وأخطاء. | يرتبط بسجل الحفظ أو المقطع والطالب. |
| MistakeRecord | نوع الخطأ وموضعه وتصحيحه. | يرتبط بالتسميع والمراجعة. |
| ContentItem | عنصر محتوى قابل للإصدار. | يتخصص إلى درس أو نشاط أو هدف أو مشروع أو دليل. |
| CurriculumVersion | نسخة منهج قابلة للنشر. | تحتوي مراحل وفصولًا ووحدات وعناصر. |
| Unit | وحدة منهجية. | تنتمي إلى فصل أو مرحلة. |
| LessonPlan | خطة درس عملية. | تعتمد على عناصر محتوى ومجموعة وتاريخ. |
| Skill | مهارة قابلة للتقييم. | ترتبط بمعايير ومجالات. |
| MasteryCriterion | معيار إتقان قابل للتعديل. | يرتبط بمهارة ومستوى أو سلم تقييم. |
| Assessment | تقييم مؤرخ متعدد المجالات. | يرتبط بالطالب والمعيار والمربي. |
| Goal | هدف طالب أو مجموعة. | يرتبط بمؤشر تقدم وموعد مراجعة. |
| Project | مشروع تربوي. | يرتبط بالمحتوى والطلاب والمراحل. |
| PortfolioEntry | شاهد أو إنجاز في ملف الطالب. | يرتبط بمشروع أو مهارة أو درس. |
| FeedbackEntry | تغذية راجعة وخطوة تالية. | ترتبط بتقييم أو درس أو طالب. |
| TeacherGuideItem | محتوى دليل المربي بإصدارات. | يشمل فلسفة المنهج وإدارة الحلقة والتدريب. |
| Resource | مرجع أو مادة محلية. | يرتبط بمحتوى مع مسار محلي اختياري. |
| ReportDefinition | تعريف تقرير ومعايير عرضه. | يستخدم بيانات قراءة ولا يغير المصدر. |
| BackupRecord | سجل عملية النسخ والتحقق والاستعادة. | يرتبط بمسار وحالة ووقت ونتيجة تحقق. |
| Setting | إعداد محلي غير حساس. | يملك نطاقًا ومفتاحًا وإصدارًا. |
| AuditEntry | سجل عمليات حساسة مستقبلًا. | يرتبط بمستخدم وكيان وعملية. |

## حقول وعلاقات مشتركة

تحتاج الكيانات التشغيلية إلى معرف، وتاريخ إنشاء وتعديل، وحالة أرشفة عند اللزوم، ومؤلف أو مصدر التعديل. تحتاج السجلات التربوية إلى تاريخ الحدث لا تاريخ الإدخال فقط. ترتبط سجلات الطالب بنطاق الحلقة أو المؤسسة لمنع خلط البيانات عند التوسع.

## الفهارس المقترحة

تُفهرس سجلات الحضور والحفظ والمراجعة والتقييم حسب الطالب والتاريخ، وتُفهرس عناصر المحتوى حسب النسخة والنوع والحالة، وتُفهرس المشاريع حسب الطالب والحالة، والنسخ الاحتياطية حسب وقت الإنشاء والحالة. لا تُنشأ فهارس بلا قياس أو حاجة استعلامية.

## بيانات لا ينبغي تخزينها

لا تُخزن كلمات مرور كنص صريح، ولا صور الأطفال أو التسجيلات الصوتية أو الفيديو تلقائيًا، ولا نصوص محادثات الأسرة غير اللازمة، ولا بيانات صحية أو معرفات رسمية أو بيانات موقع، ولا مفاتيح API أو أسرار داخل قاعدة البيانات. تُحفظ الملاحظات الحساسة بسياسة وصول منفصلة عند اعتمادها.

## ERD منطقي مختصر

Organization ← Circle ← Group ← Student. Student ← AttendanceRecord, MemorizationRecord, ReviewRecord, Assessment, Project, PortfolioEntry, Goal, FeedbackEntry. CurriculumVersion ← Unit ← ContentItem، ويرتبط ContentItem بـ LessonPlan وTeacherGuideItem وSkill وProject. BackupRecord وSetting وAuditEntry تعمل على مستوى المؤسسة أو التطبيق.

## كيانات المصدر وContent Provenance

تُضاف أو تُفصل الكيانات التالية مستقبلًا دون إنشاء قاعدة الآن:

| الكيان | الغرض | العلاقات والحقول المهمة |
|---|---|---|
| SourceRegistryEntry | سجل المصدر الأساسي. | معرف المصدر، الاسم، المؤلف، المستوى، المجال، الكتاب، الطبعة، الناشر، المرجع، الترخيص، الحالة، الاعتماد، المراجع والتاريخ. |
| SourceEdition | إصدار أو طبعة محددة للمصدر. | المصدر، رقم الإصدار، الناشر، السنة، الترخيص، المرجع. |
| SourceReview | مراجعة المصدر وقرار حالته. | المصدر، المراجع، الحالة، السبب، التاريخ، الحاجة إلى مختص. |
| ContentType | تصنيف المادة المعروضة. | نص شرعي، تفسير، شرح عالم، مسألة علمية، طريقة تربوية، نشاط، مشروع. |
| ContentVersion | نسخة محتوى قابلة للنشر. | العنصر، الإصدار، الحالة، تاريخ النشر، المراجع. |
| ContentProvenance | سلسلة أصل المحتوى. | المصدر، المؤلف، الكتاب، الموضع، الإصدار، نوع المحتوى، المدخل، المراجع، الاعتماد. |
| ContentReview | مراجعة واعتماد المحتوى. | المحتوى، المراجع، القرار، السبب، التاريخ، نطاق الاعتماد. |
| QuranTextVersion | إصدار مرجعي للنص القرآني. | المصدر، الإصدار، provenance، checksum، حالة الاعتماد، تاريخ المراجعة. |
| QuranIntegrityCheck | نتيجة فحص سلامة النص. | إصدار النص، نوع الفحص، النتيجة، البصمة، التاريخ، المنفذ. |
| CurriculumDomain | مجال تربوي مرتبط بالأصل والمصادر المساندة. | الاسم، الوصف، المصدر المرجعي، الحالة، الإصدار. |
| CurriculumSourceLink | علاقة المجال أو الوحدة أو المحتوى بالمصدر. | المجال/الوحدة/المحتوى، المصدر، نوع الرابط، موضع المرجع، حالة المراجعة. |

لا تُكرر هذه الكيانات `Resource` و`Skill` و`ContentItem` بلا سبب؛ يمكن ترقية `Resource` إلى سجل مصدر موحد، وربط `ContentItem` بإصداره وprovenance، مع إبقاء `SourceReview` سجلًا تاريخيًا مستقلًا.

## حماية النص القرآني

لا يُعامل نص القرآن كحقل تحرير عادي. يرتبط بإصدار مصدر محدد وبصمة تحقق وحالة اعتماد ومراجعة بشرية. أي تغيير في المصدر أو الإصدار ينشئ دورة اعتماد مستقلة ولا يعدل السجل المعتمد في مكانه.

## العلاقة المنطقية المحدثة

القرآن وإصداره المرجعي في مركز مصفوفة المحتوى؛ وترتبط به المجالات والوحدات والمحتوى عبر `CurriculumSourceLink`. يرتبط `ContentItem` بـ `ContentVersion` و`ContentProvenance` و`ContentReview`، ويرتبط التبسيط بالمصدر الأصلي والعمر المستهدف ومعد التبسيط وحالة مراجعته.

## نموذج التصنيف الرئيسي والعلاقات

يُفهم النموذج المنطقي على المسار: `QURAN / SHARIA_REFERENCE → CURRICULUM_DOMAIN → EDUCATIONAL_GOAL → CURRICULUM_UNIT → TOPIC → CONTENT → SOURCE → CONTENT_TYPE → AGE/STAGE → ACTIVITY → APPLICATION → ASSESSMENT → LEARNING_OUTCOME`.

تسمح العلاقات المتعددة بربط الهدف بمجال رئيسي ومجالات ثانوية، وربط الوحدة بأكثر من هدف، والموضوع بالوحدة، والمحتوى بالمصدر وبالمجال. لا تُكرر المادة لتلبية أكثر من مجال؛ تحفظ الروابط في كيان علاقة مستقل.

## إضافات التصنيف

تُضاف مفاهيم `Topic` و`LearningOutcome` و`CrossDomainLink` أو ما يكافئها منطقيًا. يصف `CrossDomainLink` المجال الرئيسي والمجالات الثانوية ونوع العلاقة، بينما يصف `LearningOutcome` الأثر أو النمو الناتج عن التطبيق والتقويم.

تظل `CurriculumDomain` مرتبطة بالمرجعية القرآنية والمصادر المساندة، وتبقى `ContentType` و`SourceLevel` و`ContentProvenance` منفصلة؛ فلا يُستنتج نوع النص من المجال وحده.

## سلامة الإصدارات القرآنية

يرتبط `QuranTextVersion` بمصدر وطبعة وإصدار وprovenance وبصمة وحالة اعتماد. تسجل `QuranIntegrityCheck` نتيجة كل فحص، ويؤدي الاختلاف إلى فشل واضح لا إلى تصحيح صامت. التفسير والتبسيط والشرح كيانات منفصلة عن النص القرآني.

## تمثيل الجوانب وهرم الثقة

يمكن تمثيل الجانب الأعلى في `CurriculumDomain` أو كيان تصنيف أب، مع إبقاء المجال التفصيلي في سجل مستقل. ترتبط الأهداف بمجال رئيسي ومجالات ثانوية، ولا يكرر المحتوى عند تعدد الروابط.

يحتاج سجل المصدر منطقيًا إلى `TrustLevel` مستقل عن `SourceLevel` و`ReviewStatus`. يصف الأول موقع المادة في هرم الاستخدام، ويصف الثاني عائلة المصدر، بينما تصف الحالة دورة المراجعة. يجب أن تدعم العلاقة المصدرية العمل المحدد والمؤلف والطبعة والموضع والاستخدام المسموح والمقيد.

تتسع `ContentProvenance` لتشمل سلسلة الثقة: المحتوى → النوع → المصدر → المؤلف → الكتاب/العمل → الطبعة → الموضع → المراجع → تاريخ الاعتماد → الإصدار. لا يعني اكتمال السلسلة أن المصدر معتمد تلقائيًا.
