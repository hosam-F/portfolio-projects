# قاموس البيانات

## التصنيفات

| التصنيف | أمثلة | قاعدة التعامل |
|---|---|---|
| بيانات المستخدم | Student, GuardianLink, Teacher, Group. | أقل قدر لازم، نطاق وصول، لا بيانات حساسة غير مبررة. |
| بيانات المنهج | CurriculumVersion, Unit, Lesson, Skill, Criterion. | إصدارات ونشر ومراجعة، مستقلة عن الطلاب. |
| بيانات التشغيل | Attendance, MemorizationRecord, ReviewRecord, Assessment, Goal. | مؤرخة ومؤلفة وقابلة للتتبع، لا حذف صامت. |
| بيانات التقارير | ReportDefinition ولقطات معتمدة عند الحاجة. | مشتقة وقابلة لإعادة التوليد، بصلاحيات واضحة. |
| بيانات النظام | Setting, BackupRecord, AuditEntry. | لا أسرار صريحة، ونطاق ومراجعة واحتفاظ مناسب. |

## المفاهيم الأساسية

| المفهوم | التعريف | أمثلة حقول | ما لا يخزن |
|---|---|---|---|
| Student | متعلم مسجل في نطاق حلقة. | معرف، اسم عرض، مرحلة، حالة، تواريخ. | معرفات رسمية وصور وبيانات صحية افتراضيًا. |
| GuardianLink | علاقة تواصل مصرح بها. | نوع العلاقة، وسيلة تواصل، حالة الموافقة. | محادثات كاملة أو تفاصيل غير لازمة. |
| MemorizationRecord | حدث حفظ أو تسميع لمقطع. | الطالب، المقطع، التاريخ، النتيجة، المؤلف. | تسجيل صوتي تلقائي. |
| ReviewRecord | مراجعة لمقطع مع إتقان وأخطاء. | التاريخ، نوع المراجعة، مستوى، ملاحظات. | أحكام وصمية غير قابلة للمراجعة. |
| ContentItem | عنصر منهجي قابل للإصدار. | معرف، نوع، عنوان، هدف، إصدار، حالة. | بيانات طالب داخل المحتوى. |
| Skill | قدرة تربوية قابلة للملاحظة. | المجال، الوصف، الشواهد، الحالة. | تقييم نهائي غير مؤرخ. |
| Assessment | قياس نمو في مجال أو معيار. | الطالب، المعيار، المستوى، التاريخ، التغذية. | مقارنات علنية بين الأطفال. |
| Project | مهمة تربوية ممتدة. | الهدف، المراحل، المشاركون، الحالة. | وسائط أطفال دون قرار صريح. |
| PortfolioEntry | شاهد على إنجاز أو نمو. | النوع، الوصف، التاريخ، الرابط المحلي. | رفع تلقائي للوسائط. |
| BackupRecord | أثر عملية النسخ أو الاستعادة. | المسار، الوقت، الإصدار، الفحص، النتيجة. | بيانات دخول أو أسرار. |

## قواعد الحقول

كل حقل يحتاج اسمًا دلاليًا ونوعًا ووصفًا وقيودًا ومصدرًا وسياسة احتفاظ. تُفصل التسمية الداخلية عن النص الظاهر للمستخدم، وتُراعي العربية والتواريخ والمنطقة الزمنية المحلية.

## قاموس مستويات التقييم

المستويات المقترحة هي مبتدئ، نامٍ، متقن، متقدم، لكنها بيانات قابلة للتعديل وليست ثوابت داخل البرنامج. يحتفظ التقييم بمعرف المستوى وإصداره ووصف معيار الملاحظة.

## مفاهيم المصدر والأصل

| المفهوم | التعريف | بيانات أساسية |
|---|---|---|
| SourceRegistryEntry | سجل مصدر قابل للمراجعة والتوسع. | المعرف، المستوى، المؤلف، الإصدار، الترخيص، الحالة، المراجع. |
| SourceEdition | طبعة أو إصدار محدد. | الناشر، السنة، رقم الإصدار، المرجع. |
| SourceReview | قرار مراجعة مصدر. | المراجع، الحالة، السبب، التاريخ، الحاجة إلى مختص. |
| ContentType | طبيعة المادة المعروضة. | نص شرعي، تفسير، شرح، مسألة، طريقة، نشاط، مشروع. |
| ContentProvenance | سلسلة أصل المحتوى. | المصدر، الموضع، الإصدار، المنشئ، المراجع، الاعتماد. |
| QuranTextVersion | إصدار نص قرآني مرجعي. | المصدر، الإصدار، checksum، الحالة، المراجعة. |
| QuranIntegrityCheck | فحص سلامة إصدار النص. | البصمة، النتيجة، نوع الفحص، التاريخ. |
| CurriculumSourceLink | علاقة المنهج بالمصدر. | المجال، الهدف، الوحدة، المحتوى، المصدر، النوع، العمر، التقويم. |

## مستويات وحالات لا تخلط

المستوى يصف طبيعة المصدر: شرعي أصلي أو تراثي/علماء أو تربوي/علمي حديث. الحالة تصف دورة المراجعة: مقترح أو قيد المراجعة أو معتمد أو موقوف أو مستبعد. أما نوع المحتوى فيصف ما يراه المستخدم: نص شرعي أو تفسير أو شرح عالم أو مسألة علمية أو طريقة أو نشاط أو مشروع.

لا يجعل أي حقل من هذه الحقول المصدر وحيًا أو معتمدًا تلقائيًا. وتبقى التبسيطات مرتبطة بمصدرها الأصلي وبالعمر ومعد التبسيط وحالة مراجعته.

## مفاهيم taxonomy الجديدة

| المفهوم | التعريف المنطقي |
|---|---|
| Subdomain | تقسيم تفصيلي داخل مجال رئيسي، قابل للتعديل. |
| QuranReferenceRelation | يحدد هل علاقة الموضوع بالقرآن نص مباشر أو صلة عامة أو لا توجد علاقة مباشرة. |
| SunnahReference | مرجع سنة منفصل مع تخريج وحالة مراجعة، لا يدمج مع النص القرآني. |
| Practice | ممارسة عملية ناتجة عن النشاط، منفصلة عن النشاط والتقويم. |
| ExpectedImpact | أثر متوقع قابل للملاحظة، لا حكم كلي على الطالب. |
| MentorPathStage | مرحلة في مسار صناعة المربي، لا تساوي Age Stage ولا User Role. |
| TransitionEvidence | شاهد انتقال بين مراحل المسار، يرتبط بناتج وكفاءة وسلوك وأمانة علمية. |

## المجالات الثمانية

الإيمان والعقيدة، العبادة والتزكية والأخلاق، العلم والثقافة، التفكير والبيان، الصحة والبدن والقوة، العمل والمهارة والإنجاز، الأسرة والمجتمع والإصلاح، والمال والمسؤولية الاقتصادية. ترتبط كل منها بواحد من الجوانب الثلاثة العليا.
