# Curriculum Source Matrix

## الغرض

تربط المصفوفة المنهج بالمصدر والأصل المرجعي، وتمنع بناء محتوى منفصل عن سياقه أو خلط أنواع المواد.

## المسار الأساسي

> المجال → الهدف التربوي → المرحلة → الوحدة → المحتوى → المصدر → مستوى المصدر ونوعه → العمر → النشاط → طريقة التقويم

يبقى القرآن في مركز المصفوفة بوصفه الأصل المرجعي، بينما توضح الروابط دور التفسير والشرح والطريقة التربوية والمصادر العلمية والأنشطة والمشروعات.

## الحقول المقترحة

| الحقل | الوصف |
|---|---|
| Domain | المجال التربوي. |
| Educational Objective | الناتج المقصود القابل للملاحظة. |
| Stage and Age | المرحلة والعمر المستهدف. |
| Unit and Content | الوحدة وعنصر المحتوى وإصداره. |
| Source ID and Edition | المصدر والطبعة أو الإصدار. |
| Source Level | شرعي أصلي، تراثي/علماء، تربوي/علمي حديث. |
| Content Type | نص شرعي، تفسير، شرح، مسألة، طريقة، نشاط، مشروع. |
| Quran Reference | السورة أو المقطع المرجعي عند وجوده. |
| Activity | النشاط والمدة والأدوات. |
| Assessment | طريقة التقويم ومعيار الإتقان. |
| Review State | حالة مراجعة العلاقة والمحتوى. |

## قواعد المصفوفة

لا تكفي الإشارة إلى عنوان كتاب؛ يجب تحديد الموضع والإصدار وحالة المراجعة. لا تنتقل علاقة إلى حالة منشورة دون مصدر ووسم ونوع واضحين. يمكن أن يكون لوحدة أكثر من مصدر، لكن لا تتساوى المستويات تلقائيًا.

## دورة التحسين

تدعم المصفوفة المسار: مصدر مرجعي → وحدة ودرس → حصة ونشاط → ممارسة الطالب → تقويم وملاحظة → تحسين المحتوى. لا تعني المصفوفة أن الملاحظة التشغيلية تعدل المصدر أو النص المعتمد مباشرة.

## التصنيف الرئيسي المحدث

المسار المرجعي هو:

> `QURAN / SHARIA_REFERENCE → CURRICULUM_DOMAIN → EDUCATIONAL_GOAL → CURRICULUM_UNIT → TOPIC → CONTENT → SOURCE → CONTENT_TYPE → AGE/STAGE → ACTIVITY → APPLICATION → ASSESSMENT → LEARNING_OUTCOME`

لا يعني هذا المسار أن كل عنصر يملك مصدرًا واحدًا فقط؛ يمكن وجود روابط متعددة بين المجال والهدف، والهدف والوحدة، والوحدة والموضوع، والمحتوى والمصدر، والمحتوى والمجال. يحتفظ كل هدف بـ `Primary Domain` ويمكن أن يرتبط بـ `Secondary Domains` دون تكرار المحتوى.

## المجالات الكبرى

تستخدم المصفوفة المجالات الروحية والإيمانية، والعقلية والعلمية والثقافية، والبدنية والصحية والعملية، والاجتماعية والأسرية، والقيادة والمسؤولية العامة، والاقتصادية والمهنية. يمكن إضافة مجال لاحقًا بقرار موثق فقط.

## أنواع المصدر والمحتوى

تسجل المصفوفة مستوى المصدر ونوعه ونوع المحتوى بالمعرفات المعيارية الواردة في `CONTENT_TYPES_AND_LABELS.md`. يجب تمييز القرآن والتفسير والشرح والطريقة والنشاط والمشروع، وتحديد الإصدار والموضع وحالة المراجعة.

## سلامة المصدر

لا تُملأ الخانات المجهولة بالتخمين؛ تستخدم `UNKNOWN` أو `PENDING_REVIEW`. لا تنتقل العلاقة إلى حالة اعتماد نهائي دون مراجعة بشرية، وتظل علاقة النص القرآني بإصداره وبصمته مستقلة عن علاقة التفسير أو التبسيط.

## تحديث الجوانب الكبرى

تُعرض المجالات التفصيلية ضمن ثلاثة جوانب كبرى: الروحي والعقلي، البدني والعملي، والاجتماعي والمسؤولية. يبقى القرآن والمرجعية الشرعية في أعلى المصفوفة، ولا يظهر كعمود موازٍ لبقية المجالات.

## تحديث هرم المصدر

تضيف المصفوفة عمود `Trust Level` من 0 إلى 5: القرآن، السنة، التفسير/الفقه/العقيدة وشروح العلماء، التراث التربوي والفكري، الدراسات الحديثة، والنشاط التطبيقي. ويظل `Source Level` العائلي و`Review Status` و`Provenance` حقولًا مستقلة.

## صيغة المصفوفة المحدثة

> الجانب الأعلى → المجال التفصيلي → الهدف → الوحدة → المحتوى → المصدر والعمل المحدد → Source Level → Trust Level → Content Type → العمر/المرحلة → النشاط → التطبيق → التقويم → الأثر

لا تعني علامة وجود مصدر في المصفوفة أنه معتمد؛ ويجب أن تعرض البطاقة المصدر والمؤلف والعمل والطبعة والموضع وحالة المراجعة والاستخدام المسموح.

## المجالات الثمانية ومسار المربي

تستخدم المصفوفة المجالات الثمانية التفصيلية المرتبطة بالجوانب الثلاثة: الإيمان والعقيدة؛ العبادة والتزكية والأخلاق؛ العلم والثقافة؛ التفكير والبيان؛ الصحة والبدن والقوة؛ العمل والمهارة والإنجاز؛ الأسرة والمجتمع والإصلاح؛ المال والمسؤولية الاقتصادية. ويضاف مسار «صناعة المربي» بوصفه مسارًا عابرًا لا مجالًا مستقلًا.

## العلاقات المرجعية المتدرجة

يصبح المسار التفصيلي:

> `DOMAIN → SUBDOMAIN → LEARNING_OBJECTIVE → AGE_STAGE → TOPIC → QURAN_REFERENCE → SUNNAH_REFERENCE → SCHOLAR_HERITAGE_SOURCES → MODERN_EDUCATIONAL_SOURCES → CONTENT → CONTENT_TYPE → SIMPLIFICATION → ACTIVITY → PRACTICE → ASSESSMENT → EXPECTED_IMPACT`

في `QURAN_REFERENCE` يجب تحديد هل العلاقة نص مباشر أو صلة عامة أو غير موجودة. لا تُنشأ علاقة مصطنعة لمجرد ملء الحقل، ولا تُنسب نظرية حديثة إلى القرآن بلا مصدر صريح.

## خريطة النمو

تدعم المصفوفة مراحل: الطالب، المتعلم، المتدبر، السائل، الباحث، المعبّر، المعين، المعلم الصغير، المربي المتدرب، والمربي المساعد. يرتبط الانتقال بالنواتج والكفاءة والسلوك والأمانة العلمية، لا بالعمر وحده، مع بقاء معايير الانتقال مفتوحة للمراجعة.
