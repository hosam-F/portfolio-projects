# سياسة ترخيص المحتوى V1

## المبدأ

لا ينتقل ترخيص مادة إلى مادة أخرى لمجرد تشابهها أو ارتباطها. لكل مادة سجل مصدر وترخيص وحالة تحقق ومراجع، ويمنع النشر عند غياب الحق أو وضوحه.

## ضوابط Tanzil

توضح صفحة Tanzil الرسمية منع تغيير النص، وضرورة نسبة المصدر ووضع الرابط وإبقاء إشعار الترخيص في النسخ المطابقة أو المحتوية على جزء جوهري من النص. لا يثبت ذلك حقوق التفسير أو الترجمة؛ لكل منهما فحص مستقل.

## دورة التحقق

تسجيل المصدر، الطبعة/الإصدار، الرابط، الترخيص، تاريخ الفحص، المراجع، نطاق الاستخدام، ثم الحالة `PROPOSED` أو `PENDING_REVIEW` أو `APPROVED` أو `SUSPENDED` أو `EXCLUDED`. لا يتحول اقتراح AI إلى مراجعة أو اعتماد.

## تثبيت Phase 3.10

لا يدخل أي تفسير أو ترجمة أو مادة خارجية إلى V1 قبل تسجيل: `Source`، والناشر أو المالك، والإصدار أو الطبعة، والترخيص، وتاريخ الاكتساب، وSHA-256 عند توفر ملف، وProvenance، وReview Status. لا يفترض ترخيص النص القرآني ترخيص تفسير أو ترجمة أو وسائط أخرى. عند نقص أي عنصر تبقى المادة `UNKNOWN` أو `PENDING_REVIEW` ولا تنشر.
