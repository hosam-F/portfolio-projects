# نموذج البيانات المنطقي للإصدار الأول V1

> هذه الوثيقة تصميم منطقي فقط. لا تنشئ جداول أو SQL أو migrations أو قاعدة بيانات.

## مبادئ النموذج

يعتمد النموذج على فصل البيانات المصدرية عن البيانات المشتقة، وفصل النص القرآني عن تفسيره ومشتقاته، وحفظ التاريخ في السجلات الحساسة، وتقليل بيانات الأطفال إلى الحد الضروري. لا يكون `Dashboard` أو `TodayQueue` مصدر الحقيقة؛ فهما قراءات مشتقة.

## العلاقات الرئيسية وCardinality

| العلاقة | Cardinality | القاعدة |
|---|---:|---|
| Organization–Circle | 1:N | الحلقة تنتمي إلى نطاق مؤسسة واحد. |
| Circle–Group | 1:N | المجموعة لا توجد خارج حلقة. |
| Group–Student | N:M عبر تسجيل زمني | يسمح بتغير المجموعة مع حفظ التاريخ. |
| Circle/Group–TeacherAssignment | 1:N | الإسناد محدد الصلاحية والفترة. |
| LessonSession–AttendanceRecord | 1:N | سجل واحد لكل طالب وجلسة بعد منع التعارض. |
| QuranTextVersion–QuranVerse | 1:N | الآيات تابعة لإصدار ثابت. |
| Student–MemorizationRecord | 1:N | كل أداء مؤرخ. |
| QuranSection–ReviewSchedule | 1:N | قائمة اليوم قراءة مشتقة. |
| CurriculumVersion–CurriculumUnit | 1:N | الوحدة تنتمي إلى إصدار. |
| CurriculumUnit–Objective | N:M | عبر علاقة مستقلة. |
| Objective–EducationalDomain | N:M | مجال رئيسي وثانوي دون نسخ المحتوى. |
| CurriculumUnit–Topic | 1:N | الموضوع تابع للوحدة. |
| Topic–Activity | N:M | النشاط قابل لإعادة الاستخدام. |
| Activity–Assessment | 1:N | التقويم قد يقيس نشاطًا أو ناتجًا. |
| Content–Source | N:M | عبر ContentProvenance. |
| TeacherTrainingUnit–MentorPathStage | N:1 | الوحدة تستهدف مرحلة نمو، لا دورًا. |
| Student–PortfolioArtifact | 1:N | الشاهد مرتبط بخصوصية ومراجع. |
| BackupRecord–AuditEntry | 1:N اختياري | عمليات حساسة قابلة للتتبع. |

## البيانات المصدرية والمشتقة

البيانات المصدرية تشمل النص القرآني المعتمد، السجلات التعليمية، الحضور، جلسات الحصة، المحتوى المنشور، المراجعات، وقرارات الاعتماد. البيانات المشتقة تشمل `TodayQueue`، مؤشرات لوحة اليوم، ملخصات التقرير، التقدم المجمع، ومواعيد المراجعة الناتجة عن سياسة قابلة للتعديل. لا يجوز تعديل البيانات المصدرية من خلال البيانات المشتقة.

## قيود عامة

تتطلب السجلات الحساسة معرفًا ونطاقًا وتاريخ حدث ومؤلفًا وحالة. تمنع القيود إنشاء سجل طفل بلا نطاق، أو سجل حضور مكرر لنفس الطالب والجلسة، أو اعتماد محتوى بلا provenance ومراجع، أو عرض نص قرآني بلا إصدار مصدر وحالة سلامة.

## الفهارس المقترحة

تقترح فهارس على: الطالب/التاريخ، المجموعة/التاريخ، السورة/رقم الآية، الإصدار/الحالة، المحتوى/الإصدار، المصدر/حالة المراجعة، المربي/المرحلة، والنسخة الاحتياطية/التاريخ. لا تنفذ الفهارس قبل قياس الاستعلامات.

## قواعد الحذف والاحتفاظ

تستخدم الأرشفة أو الحذف المنطقي للسجلات التعليمية والمراجعات والاعتمادات. لا يحذف النص القرآني المعتمد أو سجل provenance أو سجل التدقيق من خلال الاستخدام العادي. تطبق سياسة احتفاظ منفصلة على بيانات التواصل والملاحظات الحساسة.
