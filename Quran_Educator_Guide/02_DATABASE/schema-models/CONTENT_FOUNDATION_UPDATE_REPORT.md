# Content Foundation Update Report

## Executive Summary

تم تطبيق التحديثات المناسبة المستخلصة من الوثيقة المرفقة على وثائق المشروع، مع الحفاظ على القرارات السابقة وعدم تحويل المقترحات إلى تنفيذ برمجي. التحديث الأساسي هو تنظيم المجالات الستة داخل ثلاثة جوانب كبرى، وإضافة `Trust Level` من 0 إلى 5 مع الإبقاء على `Source Level` العائلي و`Review Status` و`Provenance` كحقول مستقلة.

## What Was Applied

| التحديث | الحالة |
|---|---|
| القرآن أصل ودستور ومرجع أعلى | مثبت سابقًا ومؤكد مجددًا. |
| ثلاثة جوانب كبرى | أضيفت كطبقة تنظيم أعلى دون حذف المجالات الستة. |
| فصل الفكرة عن المصدر | أضيف إلى الرؤية والسياسات وprovenance. |
| هرم الثقة 0–5 | أضيف كحقل مستقل عن عائلة المصدر وحالة المراجعة. |
| سجل المصادر القابل للتوسع | وُسع ليشمل العمل المحدد والطبعة والترخيص والاستخدامات. |
| سلسلة الثقة | وُسعت من المحتوى إلى المصدر والعمل والموضع والمراجع والإصدار. |
| الذكاء الاصطناعي | بقي مساعدًا مستقبليًا لا يولد نصًا شرعيًا ولا يعتمد مصدرًا. |
| سياسة مرحلة 0 لتأسيس المحتوى | أصبحت ممثلة في وثائق السياسة والسجل والتصنيف والمصفوفة. |

## Architectural Interpretation

لم يُستبدل قرار المستويات الثلاثة السابق مباشرة بهرم الست درجات؛ لأن ذلك كان سيمحو تمييزًا صحيحًا بين عائلة المصدر ودرجة موقعه في الاستخدام. بدلًا من ذلك، أصبح التصنيف متعدد المحاور:

| المحور | وظيفته |
|---|---|
| Source Level | عائلة المصدر: شرعي/تراثي/تربوي حديث. |
| Trust Level | موقع المادة في الهرم من 0 إلى 5. |
| Content Type | طبيعة المادة: قرآن، حديث، تفسير، نشاط، تطبيق، تقويم، وغيرها. |
| Review Status | حالة المراجعة: مقترح، قيد المراجعة، معتمد، موقوف، مستبعد. |
| Provenance | سلسلة أصل المادة وموضعها ومراجعتها وإصدارها. |

## Important Open Decisions

لا تزال هوية مصدر النص القرآني النهائي، وترخيصه، والجهة البشرية المخولة باعتماده، ومنهج اعتماد السنة، وسياسة حقوق الكتب، ونطاق إدراج النص في الإصدار الأول، قرارات تحتاج موافقة بشرية. كما لم تُنشأ أي سجلات مصدر تنفيذية أو محتوى فعلي.

## Safety and Scope

لم يتم إنشاء كود Python أو SQL، ولم تُنشأ قاعدة بيانات أو واجهة مستخدم، ولم تُثبت أي حزمة، ولم تُعدل بيئة التطوير، ولم تُستخدم API أو خدمات سحابية، ولم تُستخدم بيانات أطفال حقيقية. جميع التحديثات وثائقية ومعمارية فقط.
