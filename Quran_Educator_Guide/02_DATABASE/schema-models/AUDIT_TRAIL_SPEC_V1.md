# مواصفة سجل التدقيق V1

## الغرض

يوثق سجل التدقيق العمليات الحساسة دون نسخ بيانات الأطفال أكثر من اللازم، ويساعد على معرفة من أنشأ أو عدل أو اعتمد أو استعاد، ومتى، ولماذا عند الحاجة.

## الحد الأدنى للسجل

| الحقل | المعنى | الإلزام |
|---|---|---|
| `audit_id` | معرف الحدث | نعم |
| `actor_id` | منفذ العملية | نعم |
| `occurred_at` | وقت العملية | نعم |
| `scope_id` | المؤسسة/الحلقة | حسب النطاق |
| `entity_type` | نوع الكيان | نعم |
| `entity_id` | معرف الكيان | نعم |
| `action` | نوع العملية | نعم |
| `result` | نجاح/فشل | نعم |
| `reason` | سبب العملية عند الحاجة | حسب الحساسية |
| `change_summary` | ملخص غير سري للتغيير | حسب العملية |
| `before_hash/after_hash` | بصمات عند الحاجة | لا |

## العمليات التي تسجل

تسجل مراجعة أو اعتماد مصدر أو محتوى، تعديل نص أو محاولة تعديله، تصدير بيانات حساسة، تغيير صلاحية، أرشفة سجل تاريخي، إنشاء نسخة، تحقق نسخة، استعادة، وفشل سلامة النص القرآني.

## القيود

لا يسجل النظام نصوصًا كاملة أو ملاحظات طفل داخل سجل التدقيق إذا كان يكفي معرف وملخص. لا يسمح للمستخدم العادي بحذف سجل التدقيق. تفاصيل الاحتفاظ والوصول النهائيان ضمن `OPEN-002`.
