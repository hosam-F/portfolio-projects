# TRADE SECRET REGISTER

## التصنيف

| المستوى | أمثلة | التعامل |
|---|---|---|
| `PUBLIC` | وثائق منشورة يقرر صاحب المشروع نشرها | يمكن مشاركتها وفق قرار الإصدار. |
| `INTERNAL` | التصميمات الداخلية وخطط العمل غير المنشورة | داخل نطاق المشروع المصرح. |
| `CONFIDENTIAL` | بيانات المستخدمين، خطط الشراكة، تفاصيل المساهمين والحقوق غير المنشورة | وصول مقيد، لا خدمات خارجية، لا تصدير افتراضي. |
| `SECRET` | مفاتيح، كلمات مرور، رموز وصول، معلومات تفاوض أو أسرار تجارية حساسة | لا توضع في Git أو Markdown أو ملفات الإصدار أو السجلات العامة. |

## القواعد

لا تخزن الأسرار داخل المستودع أو ملفات Markdown أو ملفات الإصدار. لا تدخل أسرارًا أو بيانات سرية إلى Manus أو ChatGPT أو أي خدمة خارجية. تحفظ الأسرار مستقبلًا في مدير أسرار مناسب بعد قرار مستقل؛ وهذه المرحلة لا تنشئ واحدًا.

## الوضع الحالي

لم يسجل المشروع سرًا فعليًا في هذا الملف. أي قيمة تظهر لاحقًا ولا يمكن تصنيفها تكون `LEGAL_REVIEW_REQUIRED` أو `CONFIDENTIAL` مؤقتًا حتى يراجعها صاحب المشروع.
