## نطاق الملكية

يظل صاحب المشروع المرجع الافتراضي لقرارات النطاق والاعتماد والإصدارات. هذا السجل لا يمثل تسجيلًا قانونيًا أو نقلًا قانونيًا للحقوق، وأي مسألة تتطلب جهة رسمية أو محاميًا تحمل الحالة `LEGAL_REVIEW_REQUIRED`.

| الفئة | التعريف | الوضع الافتراضي |
|---|---|---|
| `PROJECT_ORIGINAL` | الرؤية، الاسم الوظيفي، التصنيف، القرارات، وثائق التصميم، المحتوى الأصلي، والمنهج المنشأ للمشروع | منسوب إلى المشروع وصاحبه، مع توثيق المؤلف والمساهمين عند الحاجة |
| `THIRD_PARTY` | مادة أو مكتبة أو خط أو صورة أو صوت أو محتوى أنشأه طرف خارجي | لا يعتبر ملكًا للمشروع؛ يخضع لسجل المصدر والترخيص |
| `PUBLIC_DOMAIN` | مادة يثبت أنها ضمن الملك العام | يلزم التحقق من الحالة والنطاق الجغرافي |
| `USER_GENERATED` | بيانات أو ملاحظات أو ملفات ينشئها مستخدم النظام | يحدد حق الاستخدام والخصوصية بسياسة مستقلة؛ لا تنسب تلقائيًا للمشروع |
| `LICENSED_CONTENT` | مادة خارجية يسمح ترخيصها باستخدامها ضمن شروط | حق استعمال محدود وفق الترخيص، لا ملكية أصلية |
| `UNKNOWN` | أصل لم يثبت مالكه أو مصدره أو ترخيصه | ممنوع اعتباره ملكًا للمشروع أو إدخاله في V1 |

## فصل المصالح

يجب فصل صاحب المشروع عن المصنفات الأصلية، والمواد الخارجية المرخصة، ومساهمات الأفراد، وأدوات التطوير، والبيانات التي ينشئها المستخدمون. لا يثبت استخدام Manus أو ChatGPT أو أي أداة ملكية للأداة أو نقلًا للمشروع إليها.

## ملاحظة قانونية

هذا سجل حوكمة داخلي وليس رأيًا قانونيًا أو تسجيلًا رسميًا للملكية الفكرية أو العلامة التجارية.
