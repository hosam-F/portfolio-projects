# VERSION PROVENANCE POLICY

## السلسلة

`Release → Manifest → File Hashes → SHA-256 → Change Log → Approval → Archive`

## الحد الأدنى لكل إصدار

| العنصر | المطلوب |
|---|---|
| Release | رقم واسم الإصدار ونطاقه |
| Manifest | قائمة الملفات والأصول الداخلة |
| File Hashes | بصمات الملفات المؤثرة |
| SHA-256 | خوارزمية التحقق من السلامة |
| Change Log | ما تغير وسبب التغيير |
| Approval | صاحب الاعتماد والمراجعة والتاريخ |
| Archive | نسخة محلية محفوظة قابلة للاسترجاع |

## القواعد

لا يضاف أصل خارجي إلى إصدار بلا Content Origin وLicense Register وprovenance. لا تعتبر SHA-256 إثباتًا قانونيًا مستقلًا للملكية؛ إنها أداة سلامة وتطابق. لا تنشر أداة أو نسخة باسم المشروع قبل اعتماد صاحب المشروع.

## الإصدارات المستقبلية

يجب ألا يعدل إصدار منشور هدميًا. ينشأ إصدار جديد، وتربط علاقته بالإصدار السابق، وتحفظ قائمة التغييرات ومراجعة حقوق الأصول الخارجية. تبقى المواد ذات الحالة `UNKNOWN` خارج Manifest الإصدار.
