# IP RELEASE CHECKLIST V1

## قبل الإصدار

| الفحص | الحالة المطلوبة | الوضع الحالي |
|---|---|---|
| صاحب المشروع مثبت | نعم | نعم: م/ حسام الجرافي |
| كل أصل مصنف | لا UNKNOWN في الإصدار | غير مكتمل |
| مصدر كل مادة خارجية | Source/Author/URL/Version | غير مكتمل لبعض المواد |
| الترخيص موثق | License + نطاق الاستخدام | غير مكتمل |
| Attribution موجود | حسب الترخيص | جزئي |
| صلاحية التعديل والتوزيع واضحة | نعم | جزئي |
| Provenance مكتمل | نعم | جزئي |
| المساهمون مسجلون | نعم | جزئي؛ لا يوجد مساهمون آخرون موثقون |
| اتفاقات المساهمين | عند الحاجة | غير مطلوب حاليًا عدا أي مساهم جديد |
| الأسرار خارج المستودع | نعم | لم تسجل أسرار |
| العلامة مصنفة | نعم أو LEGAL_REVIEW_REQUIRED | مصنفة وغير مسجلة رسميًا |
| Manifest وبصمات | نعم للإصدار | لم ينشأ إصدار |
| موافقة الإصدار | صاحب المشروع | لم يبدأ إصدار |

## منع الإصدار

يوقف الإصدار إذا وجد مصدر مجهول، أو ترخيص مجهول، أو مالك مجهول، أو مساهم بلا اتفاق مناسب، أو محتوى خارجي بلا provenance، أو سر داخل المستودع، أو اسم/علامة غير مصنفة. لا تعتبر SHA-256 وحدها إثبات ملكية قانونيًا.

## الحالة

هذه القائمة توثيقية لمرحلة ما قبل البرمجة. لا تعني اجتياز بوابة الإصدار أو نشر المشروع.
