# تقرير Phase 3.9 — حماية الملكية الفكرية وأصل المشروع

## الحالة

نفذت المرحلة توثيقيًا فقط. لم يُكتب كود، ولم تُنشأ قاعدة بيانات، ولم ينزل القرآن، ولم تثبت Dependencies، ولم ينشر المشروع، ولم يرفع أي ملف إلى الإنترنت، ولم تنشأ حسابات أو تسجّل ملكية قانونية نيابة عن صاحب المشروع.

## صاحب المشروع

صاحب مشروع «دليل المربي القرآني / صُنّاع المربي والمفكر» هو **م/ حسام الجرافي**. وهو صاحب قرارات النطاق والاعتماد، والمشرف على التطوير، وصاحب الاعتماد النهائي للقرارات التوثيقية، والمرجع في اعتماد الإصدارات ما لم يقرر خلاف ذلك. ثبت ذلك في `DECISIONS.md` عبر `ADR-028` وفي `docs/IP/OWNERSHIP_REGISTER.md`.

لا يفترض النظام وجود مالك آخر. ولا تملك Manus أو ChatGPT أو أدوات الذكاء الاصطناعي أو أدوات التطوير المشروع لمجرد استخدامها.

## الأصول الأصلية للمشروع

تشمل الأصول الأصلية المحتملة رؤية المشروع، الاسم الوظيفي، الوثائق، القرارات، التصنيف، التصميم المعماري، المحتوى التربوي الذي ينشئه المشروع، ونماذج المنهج. تصنف هذه الأصول `PROJECT_ORIGINAL` عندما يثبت إنشاؤها داخل المشروع، مع تسجيل المساهمين إن وجدوا.

## الأصول الخارجية والمرخصة

سجلت النص القرآني العربي Tanzil Uthmani 1.1 بوصفه مادة خارجية مرخصة مشروطة، لا ملكية أصلية للمشروع. أما التفاسير والترجمات والصوت والصور والمحتوى التربوي الخارجي والمكتبات والخطوط والأيقونات فتحتاج سجلات مستقلة للمالك والترخيص والإصدار والنسبة وصلاحيات التعديل والتوزيع. أي أصل مجهول يصنف `UNKNOWN` أو `PENDING_REVIEW` ولا يستخدم في V1.

## الأصول المجهولة

توجد مواد خارجية لم يحدد لها مصدر أو ترخيص أو مالك في هذه المرحلة، خصوصًا أي تفسير أو ترجمة أو وسائط لم تسجل بعد. لا تعتبر هذه المواد ملكًا للمشروع ولا تدخل في إصدار V1. الحالة الإجرائية لها `UNKNOWN` و`LEGAL_REVIEW_REQUIRED` عند وجود مسألة قانونية.

## المساهمون

سجل المساهمون في `CONTRIBUTOR_REGISTER.md`. الموثق حاليًا هو صاحب المشروع، والأدوات المساعدة بوصفها أدوات لا ملاكًا. لا يفترض نقل ملكية أي مساهم بشري دون اتفاق مناسب للملكية والسرية والمراجعة.

## الأسرار

أنشئ `TRADE_SECRET_REGISTER.md` بمستويات `PUBLIC` و`INTERNAL` و`CONFIDENTIAL` و`SECRET`. لم تسجل أسرار فعلية داخل هذا الملف. يمنع وضع مفاتيح الوصول وكلمات المرور والأسرار التجارية في Git أو Markdown أو ملفات الإصدار.

## العلامة والاسم

سجل `BRAND_PROTECTION_REGISTER.md` الاسمين: «دليل المربي القرآني» و«صُنّاع المربي والمفكر». لم يدّع المشروع تسجيل علامة تجارية أو حجز نطاق أو حماية رسمية. أي تسجيل أو بحث قانوني يحمل `LEGAL_REVIEW_REQUIRED`.

## Provenance والإصدارات

أنشئت `VERSION_PROVENANCE_POLICY.md` لتوثيق Release وManifest وبصمات SHA-256 وسجل التغييرات والاعتماد والأرشفة. البصمة أداة سلامة وتطابق، وليست إثباتًا قانونيًا مستقلاً للملكية.

## الذكاء الاصطناعي

تنص `AI_ASSISTANCE_POLICY.md` على أن AI مساعد وليس مالكًا أو مصدر سلطة دينية، وأن كل مخرج مهم يحتاج مراجعة بشرية، وأن البيانات السرية وبيانات الأطفال لا تدخل خدمة خارجية، وأن AI لا يعتمد مصدرًا ولا يغير حالة `Approved`.
