# معمارية المنهج والمحتوى

## الهدف

يُعامل المنهج بوصفه محتوى تربويًا قابلًا للتطور، لا مجموعة نصوص داخل البرنامج. يسمح النظام بإضافة وتعديل المراحل والفصول والوحدات والدروس والأهداف والأنشطة والتمارين والمشروعات والمهارات ومعايير الإتقان، مع الاحتفاظ بإصدارات واضحة.

## التسلسل المنهجي

| المستوى | الغرض |
|---|---|
| Stage | مرحلة عمرية أو تربوية ذات خصائص وأهداف عامة. |
| Term | فصل أو فترة زمنية داخل المرحلة. |
| Unit | وحدة مترابطة حول معنى أو مهارة أو سورة أو مشروع. |
| Lesson | درس قابل للتنفيذ في جلسة أو أكثر. |
| Objective | ناتج تعلم قابل للملاحظة. |
| Activity | نشاط يترجم الهدف إلى ممارسة. |
| Exercise | تمرين فردي أو جماعي. |
| Project | مهمة ممتدة تنتج شاهدًا أو خدمة أو عرضًا. |
| Skill | قدرة تنمو عبر وحدات متعددة. |
| Mastery Criterion | وصف قابل للملاحظة لمستوى الإتقان. |

## الإصدارات والنشر

يمر المحتوى بحالات مسودة، مراجعة، معتمد، منشور، مؤرشف. لا تعدل النسخة المنشورة تعديلًا هدّامًا؛ ينشأ إصدار جديد ويرتبط به تاريخ النشر ومراجع المراجعة. تحتفظ الخطة بالإصدار الذي اعتمدته حتى لا تتغير السجلات التاريخية بأثر رجعي.

## تصميم الدرس

ينبغي أن يصف الدرس الهدف والسياق والمدة والتمهيد والنشاط والتطبيق والأسئلة والتقويم والتغذية الراجعة والواجب أو الخطوة التالية. تُترك مدة 70 دقيقة وتوزيع الأيام الخمسة كقوالب قابلة للتعديل وليست قيودًا برمجية.

## دليل المربي

يمثل دليل المربي نوعًا من المحتوى المنهجي، وله تصنيف وإصدار وحالة نشر. تشمل أقسامه فلسفة المنهج، إدارة الحلقة، خطة الحصة، خصائص المراحل، طرق التدريس، الحوار، التدبر المنضبط، تعليم الأقران، التقويم، التعامل مع الأخطاء، حماية الطفل، الأسرة، المشاريع وتدريب المربي.

## قابلية التوسيع

تُفصل المعاني التعليمية عن العرض، وتُستخدم معرفات المحتوى بدل ربط الوحدات بأسماء ثابتة. يمكن لاحقًا إضافة لغات وترجمات ووسائط صوتية ومرئية ونسخ مخصصة لمؤسسات مختلفة دون تغيير السجلات الأصلية.

## القرآن مركز المصفوفة

لا يظهر القرآن في نموذج المنهج كموضوع جانبي مستقل عن بقية التربية؛ بل هو الأصل المرجعي الذي تُربط به المجالات الروحية والعقلية والبدنية والعملية والاجتماعية. لكل وحدة أو محتوى علاقة موثقة بالمصدر المرجعي والمصادر المساندة ونوع المادة.

## مستويات المادة التعليمية

تُوسم المواد بوضوح: نص شرعي، تفسير، شرح عالم، مسألة علمية، طريقة تربوية، نشاط تطبيقي، أو مشروع. لا يسمح العرض بخلط الوسم أو إظهار مادة مشتقة وكأنها المصدر الأصلي.

## مصفوفة المنهج والمصدر

تتبع كل علاقة المسار: المجال ← الهدف التربوي ← الوحدة ← المحتوى ← المصدر ← مستوى المصدر ونوعه ← العمر ← النشاط ← طريقة التقويم. تحفظ العلاقة وإصدارها وحالة مراجعتها، ويمكن تحديثها دون تغيير بنية البرنامج.

## التبسيط التربوي

عند تبسيط مصدر صعب لعمر معين، يحفظ النظام العلاقة بين المصدر الأصلي، والفكرة أو النص الأصلي، والتبسيط، والعمر المستهدف، ومعد التبسيط، وحالة المراجعة. لا يعرض التبسيط بوصفه كلام المؤلف الأصلي.

## المجالات المرتبطة بالأصل

يمكن تعريف مجالات الإيمان والعلم والعقيدة والعبادة وتزكية النفس والأخلاق والثقافة، والقوة والصحة والعمل والمسؤولية، والأخوة والأسرة والمسجد وخدمة المجتمع والإصلاح، إضافة إلى المجالات القرآنية والتعليمية واللغوية. تبقى القائمة بيانات قابلة للتعديل وحساسة للمراجعة التربوية.

## البنية التربوية العليا

تُنظم المجالات الستة داخل ثلاثة جوانب كبرى: روحي وعقلي، بدني وعملي، واجتماعي ومسؤولية. هذا تنظيم هرمي/عرضي لا يلغي المجالات التفصيلية ولا يجعل القرآن مجالًا رابعًا أو سابعًا؛ فالقرآن والمرجعية الشرعية طبقة تأسيسية عليا.

## هرم الثقة للمصادر

يستخدم المنهج محورًا إضافيًا من Trust Level 0 إلى 5: القرآن، السنة، التفسير والفقه والعقيدة وشروح العلماء، التراث التربوي والفكري، الدراسات الحديثة، ثم النشاط التطبيقي. هذا المحور يصف موقع المادة في هرم الاستخدام ولا يحل محل حالة المراجعة أو الترخيص أو provenance. لا يصبح المصدر معتمدًا بمجرد وضعه في درجة.

## التفصيل الثماني للمجالات

تتفرع الجوانب الثلاثة إلى ثمانية مجالات: الإيمان والعقيدة، العبادة والتزكية والأخلاق، العلم والثقافة، التفكير والبيان، الصحة والبدن والقوة، العمل والمهارة والإنجاز، الأسرة والمجتمع والإصلاح، والمال والمسؤولية الاقتصادية. تبقى هذه المجالات بيانات قابلة للتعديل، ولا يضاف مجال جديد دون قرار موثق.

## مسار صناعة المربي

«صناعة المربي» مسار تصاعدي عابر للمجالات، وليس مجالًا تاسعًا: الطالب، المتعلم، المتدبر، السائل، الباحث، المعبّر، المعين، المعلم الصغير، المربي المتدرب، المربي المساعد. لا يعتمد الانتقال على العمر وحده، بل على نواتج وكفاءة وسلوك وأمانة علمية؛ ومعايير الانتقال التفصيلية غير محسومة بعد.

## علاقة الموضوع بالقرآن

عند بناء وحدة أو موضوع، يميز النظام بين نص قرآني مباشر، وآيات ذات صلة عامة، وموضوع تربوي أو علمي يستفيد من قيم عامة. لا يجوز اختراع علاقة قرآنية أو نسبة نظرية حديثة إلى القرآن لمجرد وجود تشابه تربوي.

## النموذج الكامل للوحدة

تتسع الوحدة منطقيًا إلى: المجال، المجال الفرعي، الهدف، المرحلة، الموضوع، المرجع القرآني، مرجع السنة، مصادر العلماء والتراث، المصادر التربوية الحديثة، المحتوى، نوعه، التبسيط، النشاط، الممارسة، التقويم، والأثر المتوقع.

## تثبيت معمارية V1

في الإصدار الأول يكون «دليل المربي» محتوى قابلًا للإصدار، ويكون «مسار صناعة المربي» مسار نمو موثقًا عابرًا للمجالات الثمانية. تسجل المنظومة إتمام الوحدات والشواهد وملاحظات المراجعة البشرية، ولا تنتج حكمًا آليًا على صلاحية المربي أو اعتماده.

تظل `Mentor Path Stage` مستقلة عن `Age Stage` و`User Role`، ويستخدم الدور التقني `TRAINEE_TEACHER` عند الحاجة إلى صلاحية تشغيلية. لا يعامل إتمام نشاط أو تسجيل شاهد بوصفه اعتمادًا نهائيًا.
