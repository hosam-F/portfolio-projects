# سياسة التصدير V1

## القرار

التصدير في V1 محلي فقط، ولا يرسل بيانات إلى خدمة خارجية. يقتصر على المستخدمين ذوي الصلاحية والنطاق المحدد، ويتطلب تأكيدًا واضحًا ويسجل في Audit Trail.

## من يستطيع التصدير؟

| الدور | التصدير المسموح |
|---|---|
| ADMINISTRATOR | تقارير وبيانات نطاقه بعد التأكيد، مع استثناء الحقول المقيدة افتراضيًا. |
| SUPERVISOR | تقارير الحلقة والمحتوى المسموح، لا ملف المؤسسة الكامل. |
| TEACHER | تقارير مجموعاته وطلابه ضمن التفويض، دون تصدير جماعي حساس. |
| TRAINEE_TEACHER | لا تصدير بيانات أطفال أو ملاحظات حساسة؛ يمكن حفظ انعكاسه أو تقرير تدريبه المحلي وفق السياسة. |
| REVIEWER | تقارير المصدر والمراجعة، دون بيانات أطفال إلا للحاجة. |
| VIEWER | لا تصدير. |

## ما يمكن تصديره؟

يمكن تصدير تقرير محلي مطبوع أو ملف تبادل مصمم وفق `JSON_CONTRACT_V1.md`، مع تحديد النطاق والفترة وإصدار المحتوى ومصدر البيانات. تصدر بيانات المصدر وprovenance عند صلاحية المراجع، وتبقى الآيات خاضعة لإشعار Tanzil وشروطه.

## ما يمنع تصديره افتراضيًا؟

تمنع التصديرات الجماعية غير المقيدة لبيانات الأطفال، وبيانات التواصل الأسري، والملاحظات الحساسة، وسجل التدقيق الكامل، ومفاتيح الإعداد أو الأسرار، وأي مادة غير مرخصة، وأي نص قرآني غير متحقق أو مصدر غير معتمد.

## ضوابط العملية

يعرض النظام ملخص ما سيصدر، والفترة والنطاق والحقول الحساسة، ويطلب تأكيدًا ثانيًا عند وجود بيانات شخصية. يسجل `actor_id` ووقت التصدير والنطاق والنتيجة والسبب عند الحاجة. يحفظ الملف في مسار محلي يختاره المستخدم، ولا يرفعه أو يرسله تلقائيًا.

## التصدير غير المقصود

تستخدم أسماء ملفات واضحة، وتحذيرًا قبل الكتابة فوق ملف، وتمنع التصدير الجماعي من شاشة عامة. لا يشتمل التصدير على بيانات مشتقة بوصفها مصدر حقيقة؛ يرفق مصدر المؤشر وفترته.


## قرار Phase 3.10

التصدير في V1 `Local-only`، ومقيد بالدور والنطاق، ويتطلب تأكيدًا صريحًا وسجل تدقيق، ويمنع التصدير الحساس افتراضيًا، ولا يدعم Cloud Export. إذا احتوى التصدير على بيانات طفل، يطبق Minimum Necessary Data ولا يضم الحقول غير اللازمة أو البيانات الحساسة بلا صلاحية صريحة.
