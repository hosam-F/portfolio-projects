# أنواع المحتوى والوسوم

## الغرض

يجب أن يعرف المعلم طبيعة المادة التي يقرأها أو يستخدمها. الوسم جزء من سلامة العرض، وليس مجرد تصنيف بحث.

| الوسم | التعريف | قاعدة العرض |
|---|---|---|
| نص شرعي | نص قرآني أو حديث صحيح وفق سياسة المشروع. | مصدر وإصدار وحالة اعتماد واضحة، وغير قابل للتحرير العادي. |
| تفسير | شرح لمعنى النص. | لا يعرض داخل كتلة النص الشرعي. |
| شرح عالم | قول أو تحليل عالم أو مؤلف. | يظهر اسم صاحبه وموضعه وحالة مصدره. |
| مسألة علمية | معرفة أو نتيجة بحث حديث. | لا تعرض كحكم شرعي لمجرد ارتباطها بالتربية. |
| طريقة تربوية | أسلوب تدريس أو مبدأ تعلم. | تذكر طبيعته ومصدره وحدود تطبيقه. |
| نشاط تطبيقي | تمرين أو إجراء تعليمي. | يذكر الهدف والعمر والمدة والمصدر إن وجد. |
| مشروع | مهمة ممتدة ذات ناتج وشاهد. | يذكر المراحل والأدوار والتقويم. |

## وسوم إضافية

يمكن استخدام وسوم المجال والمرحلة والعمر والإصدار وحالة المراجعة، لكن لا تستبدل هذه الوسوم نوع المصدر أو حالة الاعتماد.

## قواعد الجمع

قد يرتبط نشاط بمقطع قرآني ومصدر تربوي، لكن العلاقة توضح أيهما أصل وأيهما طريقة تنفيذ. وقد يرتبط التفسير بنص شرعي، لكنه لا يندمج معه في كتلة واحدة أو عنوان يوهم أنه منه.

## AI

أي مادة مقترحة بمساعدة AI تحمل وسم «اقتراح آلي — يحتاج مراجعة»، ولا يمكنها اكتساب وسم «معتمد» تلقائيًا.

## المعرفات المعيارية

| Identifier | الوسم العربي | القاعدة |
|---|---|---|
| `QURAN_TEXT` | نص قرآني | إصدار موثق غير قابل للتحرير العادي. |
| `HADITH_TEXT` | نص حديث | مصدر وحالة صحة ومراجعة مناسبة، ولا يولده AI. |
| `SCHOLARLY_TEXT` | نص عالم/باحث | ينسب إلى عمل محدد وطبعة وموضع. |
| `TAFSIR` | تفسير | شرح منفصل عن كتلة النص القرآني. |
| `FIQH` | فقه | مصدر وتصنيف ومراجعة، ولا يعرض كقرآن. |
| `AQEEDAH` | عقيدة | مصدر وتصنيف ومراجعة. |
| `EDUCATIONAL_RESEARCH` | بحث تربوي/علمي | مادة علمية لا تصبح حكمًا شرعيًا بمجرد ارتباطها بالتربية. |
| `EDUCATIONAL_METHOD` | طريقة تربوية | أسلوب أو منهج تنفيذ. |
| `EXPLANATION` | شرح | مادة مشتقة مع نسبتها. |
| `SIMPLIFICATION` | تبسيط تربوي | مرتبط بالمصدر الأصلي والعمر ومعد التبسيط. |
| `ACTIVITY` | نشاط | تطبيق تعليمي قابل لإعادة الاستخدام. |
| `EXERCISE` | تدريب | ممارسة محددة مرتبطة بهدف. |
| `APPLICATION` | تطبيق عملي | نقل التعلم إلى ممارسة. |
| `ASSESSMENT` | تقويم | أداة أو نتيجة قياس. |
| `REFLECTION` | تأمل | مراجعة ذاتية للمتعلم أو المربي. |

لا يجوز عرض `TAFSIR` أو `SIMPLIFICATION` أو `ACTIVITY` أو أي نوع مشتق على أنه `QURAN_TEXT`. وتستخدم `UNKNOWN` أو `PENDING_REVIEW` عندما لا تتوفر بيانات النوع أو المصدر.
